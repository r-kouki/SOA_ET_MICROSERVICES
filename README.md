# SOA and microservices practicals

Node.js practicals (TP) for the service-oriented architecture and microservices course.

| TP | Topic |
| --- | --- |
| [tp1](tp1) | Consuming REST APIs with different HTTP clients |
| [tp2](tp2) | REST API with Express and SQLite (person registry, rate limiting, CORS) |
| [tp3](tp3/tp-graphql) | GraphQL task management API with Apollo Server |
| [tp4](tp4/grpc-tp) | gRPC hello world service |
| [tp5](tp5/grpc-ws-reverse-proxy) | gRPC chat service behind a WebSocket reverse proxy |
| [tp6](tp6) | Kafka producer and consumer with MongoDB and an Express API |

Each folder has its own README. Install dependencies inside each folder with `npm install`.
